# За гранью

Карточные приключения в браузере. Первое приключение — **«Дело № 13 — Тихая гавань»**.

**[Играть](https://vadimlarkin.github.io/za-granyu/)**

Ранняя версия для тестирования: Искатель, восемь противников, сюжетные сцены, награды, опыт, повышение уровня и выбор перка. Интерфейс на русском языке, иллюстрации и локально создаваемые звуки.

## Как играть

Откройте ссылку и нажмите «Начать игру». Стоимость карты оплачивается сбросом других карт из руки. Оплата своим цветом даёт +50% к основному эффекту и удваивает числовой спецэффект. Серые карты не усиливаются. После победы выберите награду или откажитесь от неё ради дополнительной карты в руке на следующий бой.

Партия хранится только в открытой странице: перезагрузка сбрасывает приключение. Настройки звука, размера карт и режима интерфейса сохраняются в браузере. Воровка и Профессор пока недоступны.

## Локальный запуск

Нужен Python 3. В папке игры выполните:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8765. Двойной щелчок по index.html не заменяет сервер: игра использует модули JavaScript и загружает cards.md.

## Проверка и публикация

Нужен Node.js 22 или новее. Внешних зависимостей нет.

```sh
node scripts/test.mjs
node scripts/build.mjs
```

Сборка в `dist/` содержит только файлы игры. После отправки изменений в ветку `main` GitHub Actions запускает проверки, собирает игру и обновляет GitHub Pages. При ошибке проверок новая версия не публикуется.

В Releases сохраняются отмеченные версии. Архив веб-версии требует такого же локального сервера; это не установщик и не автономный HTML-файл.

## Устройство проекта

- `cards.md` — каталог карт, который читает игра.
- `engine.mjs` — правила боя и эффекты.
- `campaign.mjs`, `story.mjs`, `enemy-decks.mjs` — приключение, сюжет и противники.
- `progression.mjs`, `rewards.mjs` — опыт, перки и награды.
- `app.mjs`, файлы CSS и `assets/` — интерфейс, оформление и иллюстрации.
- `tests/` — проверки правил.

Рабочая Excel-книга, резервные копии и материалы подготовки остаются локально и не входят в репозиторий. Изменения Excel переносятся в игровые файлы отдельно.


## Согласованное обновление 21.09.2026

«Удар» получил «Неожиданный удар 1»: дополнительный урон по оглушённому врагу добавляется к основному удару перед защитой. При полной оплате красными картами основной урон 3, дополнительный 2. Одно уклонение предотвращает весь удар.

«Блок» получил «Укрепление»: при действующем уклонении включает оборонительную стойку до конца боя. Это бинарный эффект; сила 0 в Excel не отключает его. Стойка сохраняет остаток физической защиты между ходами, но не отменяет расход защиты от урона. Выстрел проходит сначала через магическую, затем физическую защиту и игнорирует уклонение.

Перки «Воин», «Вор», «Маг» упрощают оплату основного эффекта карт своего цвета стоимостью от 2. Для удвоения спецэффекта по-прежнему нужна вся оплата своим цветом. «Неприкосновенный запас» даёт первый добор 4 вместо 3 в каждом бою; «Бывалый» уменьшает максимальное здоровье врага на 10%, итог округляется вниз.

Стоимость пересчитана у всех 20 видов. Изменились: «Перевязка» 2→1, «Ограбить» 1→2, «Подлый удар» 2→3, «Ловкий манёвр» 1→2, «Ритуальный круг» 3→4, «Отобрать оружие» 2→3. «Грязные бинты» сохраняют ранее согласованную цену 0. «Ускорение» стало серым: скидка 1, цветового усиления нет.

Модель стоимости использует балл компонентов и запас на удвоение спецэффекта: предположение о полной одноцветной оплате — 25%. Это исходная оценка для игровых проверок, а не измеренная частота. Редкость не даёт скидку к цене. Основные эффекты, силы, бонусы и малусы пользователя сохранены.

На уровне 2 предлагаются три случайных разных перка из пяти перков этого уровня. Предложенная тройка сохраняется до подтверждения; смена предварительного выбора или награды её не меняет.

Версия 0.2.0: стартовая рука выдаётся обоим участникам до первого хода. Дальше обычный добор происходит в конце своего хода. Оглушение заставляет в начале хода сбросить случайные карты из руки, по силе эффекта. Список изменений — [CHANGELOG.md](CHANGELOG.md).

Малус сохраняется до конца следующего хода наложившего его персонажа. Оглушение сбрасывает карты лишь один раз, но остаётся доступным для сочетаний на следующем ходу атакующего. Новые наложения имеют отдельный срок. Правила длительности бонусов не изменены.
